## Project overview
A Python data analytics mini-capstone exploring relationships between study hours, attendance, and student marks. The notebook includes data inspection, cleaning, feature engineering, outlier analysis, visualizations, and summary insights.

## Run in Google Colab
1. Upload `Student_Academic_Performance_Analysis_FIXED.ipynb` to Google Colab.
2. Select **Runtime → Run all**.
3. The notebook generates its own sample dataset, so a CSV upload is not required.

## Important data note
The dataset is synthetic sample data, not real student records. Confirm that your instructor permits synthetic data before submission.
